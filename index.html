Comment utiliser cette clé ?

Copiez cette clé et utilisez-la avec la bibliothèque cryptography en Python pour chiffrer/déchiffrer des messages. Exemple : 

from cryptography.fernet import Fernet
f = Fernet(b"votre_clé_ici")
token = f.encrypt(b"Message secret")
print(f.decrypt(token))
