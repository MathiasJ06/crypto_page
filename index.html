Comment utiliser cet outil ?

1. Générez une clé Fernet en cliquant sur le bouton ci-dessus.
2. Copiez cette clé (elle sera utilisée automatiquement pour le chiffrement/déchiffrement).
3. Saisissez un message et chiffrez-le avec la clé.
4. Pour déchiffrer, collez le message chiffré et utilisez la même clé.

Note : La clé est stockée dans votre navigateur uniquement pour cette session.
